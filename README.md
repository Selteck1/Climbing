# FunTime Visual

A client-side Fabric menu prototype for Minecraft 1.21.11.

## Build

The GitHub Actions workflow builds the project on pushes to `main` and can also be started manually from the Actions tab.

After a successful build, open the workflow run and download the `funtime-visual-mod` artifact. Install the resulting JAR with Fabric Loader for Minecraft 1.21.11 and Fabric API.

Open/close the menu with **Right Shift**.

## Current scope

This is a visual menu prototype. The toggles currently change only their UI state; they do not implement gameplay features.
